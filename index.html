Bip Bip Papel-Ecommerse

Existe una necesidad de simplificar la búsqueda, selección y adquisición de regalos personalizados que combinan artículos de papelería premium, presentación elegante y opciones de personalización en una sola experiencia de compra digital. Las personas que desean realizar un obsequio distintivo pueden enfrentarse a una oferta fragmentada, esta situación genera una inversión adicional de tiempo y esfuerzo. "Bip Bip Papel" es una papeleria virtual en la cual se trabajó con lenguaje HTML, CSS y JS en el frontend y en la parte del backend Java y Springboot. El rol que desempeñe dentro del desarrollo de este proyecto fue como líder técnico, el gran desafio dentro de este proyecto fue la organización del equipo y de la delegación de las actividades, para solucionar este problema se opto por el SCRUM MASTER. y la creación de un backlog para la delegación de actividades y seguimientos de las mismas.
